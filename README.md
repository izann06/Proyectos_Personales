## 🔪 [Dark Passenger Backup](./Dark-Passenger-Backup/)

Un sistema de copias de seguridad automático, temático e inteligente. Detecta cuando conectas tu SSD externo y lanza un ritual de sincronización (basado en `robocopy`) con una interfaz gráfica espectacular y animada.

## <img src="https://raw.githubusercontent.com/immich-app/immich/main/docs/static/img/favicon.png" width="28" height="28" align="center"> Immich 🩸+ [Rama Dedicada]

Una configuración y guía completa para montar tu propia nube privada de fotos (alternativa a Google Photos) usando Docker. Te permite sincronizar todas las fotos de tu móvil de forma automática y mantener tus recuerdos seguros en tu propio servidor.

👉 **[Ver el proyecto en su rama (feature/immich)](https://github.com/izann06/Proyectos_Personales/tree/feature/immich)**

- **Tecnologías:** Docker, Docker Compose, PostgreSQL
- **Estado:** ✅ Completado y funcional
